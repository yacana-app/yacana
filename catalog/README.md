# The object catalogue

`build.py` makes the app's catalogue of deep-sky objects, `shared/ui/src/commonMain/composeResources/files/catalogue.tsv`, from [OpenNGC](https://github.com/mattiaverga/OpenNGC) by Mattia Verga, with the common names of `names.tsv`.
